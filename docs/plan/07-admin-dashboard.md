# 07. 관리자 대시보드 (Subculture Backstage)

## 7.1 수집 후보 관리

- 미검수 후보 목록
- 신뢰도순·출처순·행사순 정렬
- 원문과 자동 번역 동시 표시
- 과거 승인·거절 유사 문서 표시
- 기존 행사 데이터와 변경 제안 비교
- 원본 링크 및 저장 스냅샷 확인
- 승인·일부 승인·거절·참고 처리

## 7.2 행사 데이터 관리

- 행사 시리즈 CRUD
- 행사 및 개별 일정 CRUD
- 장소, 주최사, 작품/IP, 인물 연결
- 태그 그룹 및 태그 관리
- 공식 URL 및 출처 연결
- 상태 및 변경 이력 확인

## 7.3 수집 소스 관리

- 출처 URL 및 계정 등록
- 수집 방식 설정
- CSS Selector, XPath, JSON Path 등록
- 포함·제외 규칙 등록
- 수집 주기 및 우선순위 설정
- 마지막 성공·실패 시각 확인
- 일시중지 및 재활성화

## 7.4 번역 관리

- 언어별 번역 상태 확인
- 원문과 번역 비교
- 용어집 적용 결과 확인
- OUTDATED 번역 목록
- 번역 수정 요청 처리
- 용어집 제안 처리
- 특정 용어 변경 영향 범위 확인

## 7.5 운영 관리

- Worker Queue 상태
- 수집·분석·번역 실패 작업 재시도
- 스토리지 사용량
- API 요청량
- 알림 발송 성공·실패
- 최근 데이터 변경 감사 로그

## 7.6 관리자 인증 방식 (미결)

Phase 1 "관리자 로그인" 항목에 대해 현재까지는 로그인이 필요하다는 요구사항만 정의되어 있고, 구체적인 인증 방식은 정해지지 않았다. Core MVP 구현에 들어가기 전에 아래 중 하나로 확정이 필요하다.

- 세션 기반 로그인 (서버 세션 + httpOnly 쿠키)
- JWT 기반 로그인 (Access/Refresh 토큰 분리)
- 외부 Auth 제공자 연동 (예: Supabase Auth, Auth0 등) — 초반 인원이 1인이라는 점을 고려하면 직접 구현보다 관리 부담이 적을 수 있음

권한 역할 구분은 [10-infra-ops-security.md §보안 및 권한](10-infra-ops-security.md)의 역할 목록(ADMIN, DATA_REVIEWER 등)을 따른다.
